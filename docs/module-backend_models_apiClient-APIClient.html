Class: APIClient

backend/models/apiClient~APIClient()

Classe responsável por interagir com APIs externas:

  • OSRM (cálculo de rotas)
  • Nominatim (geocodificação direta e reversa)
  • Photon (fallback)
  • Overpass (pontos de interesse)

Inclui mecanismos de cache, controlo de taxa e fallback automático.

(async, static) getPointsOfInterest(bbox, typesopt) → {Promise.<Object>}

Obtém pontos de interesse (POIs) dentro de uma área geográfica definida, utilizando a Overpass API. A query busca nós, vias e relações com o atributo especificado.
