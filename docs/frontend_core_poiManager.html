Class: frontend/core/poiManager

frontend/core/poiManager()

new frontend/core/poiManager()

Classe responsável pela gestão de POIs e marcadores no mapa Leaflet, incluindo:

  • Localização atual do utilizador
  • Marcadores da rota (origem, destino, paragens intermédias)
  • Marcadores de POIs obtidos pela Overpass API
  • Limpeza, remoção e controlo visual dos elementos no mapa

NOTA: Esta classe não calcula rotas; apenas gere visualizações e interações do mapa.
